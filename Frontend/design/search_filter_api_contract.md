# 탐색 조건 API 전달 필드
기준: 2026-11-05. 프론트 외 파일은 수정하지 않았습니다.

## 현재 사용
- connector_types: FAST / SLOW. 서버 검색 조건.
- facility_type: 사람이 읽을 수 있는 시설 분류. 프론트 장소 필터.
- parking_free: true / false / null. 무료 / 무료 아님 / 확인 필요.
- restriction_detail: 명시적인 출입 제한 문구로 외부인 가능 / 불가 / 확인 필요를 구분.
- 분류 미상은 특정 장소 필터를 만족한 것으로 취급하지 않음.
- 외부인 이용은 결제, 충전기 가용성, 주차 빈자리와 별개.

## 백엔드 전달 필요
1. 원천 kind 및 kindDetail 코드를 공식 코드표에 따라 해석한 시설 분류.
2. 충전기별 원천 chgerType 및 정규화된 connector_standards.
3. 충전기별 output_kw. 커넥터와 출력을 같은 충전기 레코드에 연결.
4. limitYn, limitDetail 기반 access_status와 판단 근거. 누락은 UNKNOWN.
5. 결제 수단은 제공처 근거가 확인될 때만 payment_methods로 제공. QR/NFC/회원카드/자동충전 지원을 추측하지 않음.

## 충전 조건 적용 원칙
- 급속/완속은 커넥터 규격과 별개입니다.
- 출력 구간은 30 미만 / 30 이상 50 미만 / 50 이상 100 미만 / 100 이상 200 미만 / 200 이상 kW로 구분합니다.
- 시설 단위 커넥터 집합과 최대 출력만으로 필터링하면 서로 다른 충전기를 잘못 결합할 수 있습니다.
- 현재 응답은 FAST/SLOW만 전달하므로 상세 커넥터·출력 선택은 비활성입니다.
- 변경 후 탐색 필터는 조회된 결과에 적용합니다. 서버 쿼리 필터가 추가되면 SearchInput 계약도 확장해야 합니다.
