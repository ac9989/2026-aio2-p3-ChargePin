# 프론트 작업규약

이 규약은 `Frontend` 폴더의 사용자 화면과 운영 대시보드에 적용합니다. 변경 시 두 화면의 공통 디자인과 실제 연결 상태를 함께 확인합니다.

## 공통 헤더와 아이콘

- 사용자 화면과 대시보드의 로고, 제목, 우측 버튼은 같은 콘텐츠 폭과 수직 기준선에 맞춥니다.
- 화면 전환이나 글자 크기 변경으로 헤더의 높이와 좌우 위치가 달라지지 않도록 공통 헤더와 공통 스타일을 사용합니다.
- 버튼의 가로·세로 크기를 유지하고 아이콘을 버튼의 가로·세로 정중앙에 배치합니다. 포커스 표시와 접근 가능한 이름을 제공합니다.
- 좁은 화면에서는 겹침과 잘림을 피하도록 배치를 조정합니다.

## 화면 구성과 표현

- 대시보드는 운영 개요의 세 영역 요약과 각 상세 화면을 구분합니다. 카드와 제목, 차트의 간격과 안쪽 여백을 일관되게 유지합니다.
- 화이트와 차콜을 기본으로 하고 옐로우는 선택 상태와 강조에 제한적으로 사용합니다. 상태 색은 의미와 가독성을 일관되게 유지합니다.
- 추이는 선, 항목 비교는 막대, 구성 비율은 도넛 등 데이터 목적에 맞는 차트를 사용합니다. 의미 없는 계기판과 장식은 사용하지 않습니다.
- 실제 값, 현재 세션 값, 시연 값, 연결 대기 상태를 구분하고 데이터의 기준과 시점을 명시합니다. 없는 운영 수치를 만들어 표시하지 않습니다.
- 시연 메뉴는 번개 버튼 안에서 사용자 화면과 대시보드 항목을 구분합니다. 역할별 접근 제한과 서버 권한 검증을 유지합니다.
- 역할은 로그인 시 손님·하급 관리자·상급 관리자로 정해지며, 대시보드에서 권한 관리·역할 변경 UI는 제공하지 않습니다.

## 변경 전후 확인

- 공통 헤더의 크기·위치와 아이콘 정렬을 사용자 화면과 대시보드에서 함께 확인합니다.
- 일반 화면 크기와 좁은 화면에서 겹침, 잘림, 글자 대비와 스크롤을 확인합니다.
- 변경 범위에 맞는 코드 검사와 기능 확인을 수행하고, 연결되지 않은 기능은 연결 대기로 표시합니다.
- 프론트 작업 범위는 `Frontend` 폴더입니다. 다른 영역의 변경이 필요하면 담당자와 조율합니다.
