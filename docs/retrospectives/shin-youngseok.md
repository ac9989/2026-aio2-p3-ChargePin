## 맡은 역할
API 연동·검증. 장애 테스트 , QA

## 어려웠던 점 
원래는 백엔드를 하고 싶었으나, 전체적으로 개념과 경험이 매우 부족해서 웹서비스의 첫걸음부터가 어려웠음. 팀원의 배려로 QA를 하게 되었지만, 그마저도 개념이 부족해서 뭐가 뭔지 알기 어려웠고, 시스템의 전반적인 이해도가 매우 부족해서, 흐름을 파악하는데도 많은 어려움이 있었음. 이해가 부족하니 AI를 이용하는데도 불구하고, 많은 시행착오가 발생해서 작업이 많이 더뎠고 비효율적이였음. 어디에서 시작해야할지를 잘 몰라서 일단 시작하고 역으로 이동하는 등, 많이 힘들었음. 

## 해결 과정
일단 AI를 통해서 무엇을 하는 서비스를 만든 것인지 대략적인 큰 틀에서 설명하고, 어떤 모양인지, 가장 간단한 형태의 시스템이 어떻게 생길지, 뭐가 필요한지 등, 가장 기초적인 질문 부터 시작해서 점점 섬세한 것 까지 조금씩 들어가고 배웠음. 팀에 경력자가 있어서 실제 작업 환경이 어떠한지 살펴보며 어깨너머로 배우고자 했고, 맡은 직책을 수행하며 그 동안 몰랐던 부분에 대해서 상당한 개념을 배웠음. 

## 배운 점
경력자가 만든 시스템의 틀, 개발 과정 그리고 전반적인 개념들. QA를 하며 무엇을 고려해야할 지, 무엇이 있는지 등, 여러가지를 배울 수 있었음.
